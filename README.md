# 🧠 Jogo "Computador Adivinha" 🎲

Bem-vindo ao jogo *Computador Adivinha*! Esse é um jogo divertido de adivinhação em que **o computador assume o papel de detetive** e tenta adivinhar o número que você está pensando, entre 1 e 100, fazendo perguntas estratégicas! 🕵️‍♂️

## 🤔 Como funciona?

1. **Escolha um número secreto:** Pense em um número de 1 a 100 e guarde bem! Não o revele para ninguém, especialmente não para o computador! 
2. **Responda as perguntas do computador:** O computador irá tentar adivinhar seu número, fazendo perguntas que você deve responder com *sim*, *não* ou informando se o número adivinhado é maior ou menor do que o seu.
3. **Vença o computador (ou não!):** O objetivo do jogo é ver se o computador consegue adivinhar seu número com o menor número de perguntas possível.

## 📋 Exemplo de Jogo

1. **Você pensa no número** `42` 🤫
2. O computador pergunta: “O número é maior que 50?”
   - Você responde **não**
3. O computador pergunta: “O número é maior que 25?”
   - Você responde **sim**
4. O computador pergunta: “O número é maior que 37?”
   - Você responde **sim**
5. O computador pergunta: “O número é menor que 45?”
   - Você responde **sim**
6. O computador pergunta: “O número é 42?”
   - **Parabéns! O computador acertou! 🎉**

## 🔧 Tecnologias

- **Golang** para lógica do jogo e perguntas interativas
- **Console Interativo** para interação com o jogador

## 🚀 Como Jogar

1. Clone este repositório em sua máquina:
   ```bash
   git clone https://github.com/Garbelin3/computadorAdivinha.git
   cd computadorAdivinha
   ```
2. Execute o jogo:
   ```bash
   go run main.go
   ```

## 🏆 Desafio

**Desafie o computador** com números difíceis ou tente enganá-lo com suas respostas (se você se lembrar, claro!) e veja quantas perguntas ele precisará para acertar. 😏

**Divirta-se e boa sorte! O computador vai precisar dela para adivinhar o seu número! 😉**
